# ShiftOps AI submission assets

These files support the AMD Developer Hackathon ACT III submission for ShiftOps AI.

| File | Purpose |
| --- | --- |
| `ShiftOps_AI_ACT3_Pitch_Deck.pdf` | 16-page submission pitch deck. |
| `ShiftOps_AI_Demo_Final.mp4` | Public-demo walkthrough with English narration, subtitles, and guided click indicators. |
| `ShiftOps_AI_Cover_Concept.png` | Promotional cover artwork for the submission page. |

## Evidence boundary

The cover artwork is a promotional concept, not a screenshot of the deployed application. The mobile interface and some visual dashboard elements shown in the artwork are conceptual and are not claims of implemented functionality.

The demo video shows the deployed ShiftOps AI workflow. Its recommendation explanation is labelled deterministic and must not be represented as verified live AMD inference.
