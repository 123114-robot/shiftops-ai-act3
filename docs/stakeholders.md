# Stakeholders

| Stakeholder | Need | V1 involvement |
| --- | --- | --- |
| Manager | Accurate staffing | Manages employees, shifts, and leave decisions |
| Employee | Clear schedule and self-service | Maintains availability and requests leave |
| Business owner | Reduced scheduling risk | Receives a maintainable system |
| Maintainer | Explainable implementation | Uses typed boundaries and tests |

Payroll, HR, award-compliance, and messaging integrations are outside V1.
