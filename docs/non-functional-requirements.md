# Non-functional Requirements

- Hash passwords and keep secrets in environment variables.
- Enforce authentication, roles, ownership, and validation in the API.
- Use strict TypeScript and consistent errors.
- Preserve history with foreign keys and soft deactivation.
- Automate core business-rule tests.
- Support responsive desktop/tablet use and normal SME volumes.
- Do not log credentials or tokens.
- Keep dependencies and design explainable.
