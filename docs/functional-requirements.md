# Functional Requirements

1. Login, logout, and current identity.
2. Manager employee list, create, view, edit, and deactivate.
3. Employee own recurring availability update; manager read.
4. Manager shift create, edit, cancel, list, and assign.
5. Inclusive date-range shift filtering.
6. Employee leave submission/status; manager list/decision.
7. Manager weekly roster and employee personal schedule.
8. Consistent error object containing code and message.

Phase 1 implements only health and frontend-to-backend connectivity.
